# Screenshots — Guide de nommage

Placez vos captures d'écran dans ce dossier (`docs/screenshots/`) avec les noms suivants pour que la README et la documentation restent cohérents :

- `01-dashboard.png` — tableau de bord / page d'accueil
- `02-tree-overview.png` — vue générale de l'arbre
- `03-tree-member-selected.png` — arbre avec un membre sélectionné
- `04-profile.png` — fiche profil ouverte
- `05-health.png` — fiche santé affichée
- `06-timeline.png` — mémoire / timeline avec média
- `07-map.png` — carte mondiale avec pins
- `08-stats.png` — graphiques statistiques
- `09-export-pdf.png` — aperçu export PDF
- `10-admin.png` — panneau Admin / gestion des rôles

Recommandations :
- Format recommandé : PNG ou JPEG
- Résolution minimale : 1280×720 (préférer 1920×1080 pour les images détaillées)
- Taille : optimiser pour le web (< 300 KB si possible)
- Ajouter un `alt` descriptif quand vous insérez l'image dans la documentation

Si vous n'avez pas encore d'images, vous pouvez créer un fichier `.gitkeep` ici pour garder le dossier dans Git.
