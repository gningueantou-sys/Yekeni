# Checklist pré-demo — Yëkëni

Utilisez cette checklist avant la démo pour vous assurer que tout est prêt.

- [ ] Compte démo Admin créé et testé
- [ ] Compte démo Membre créé et testé
- [ ] Images de test ajoutées dans `docs/screenshots/` (noms recommandés)
- [ ] Variables d'environnement configurées :
  - [ ] `REACT_APP_SUPABASE_URL`
  - [ ] `REACT_APP_SUPABASE_ANON_KEY`
  - [ ] `REACT_APP_CLAUDE_API_KEY` (si biographie IA utilisée)
- [ ] Export PDF testé et téléchargeable
- [ ] Biographie IA testée (quota API ok)
- [ ] Plan B : site déployé sur Vercel accessible
- [ ] Test complet (connexion, CRUD, IA, export) effectué 24h avant
- [ ] Matériel de démo prêt (micro, partage d'écran)

Bonnes pratiques :
- N'utilisez pas de données personnelles sensibles pour une démo publique.
- Préparez un petit script oral pour chaque étape (30–60s par étape).
